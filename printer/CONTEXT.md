# Printer 项目术语表

## 核心术语

| 术语 | 定义 |
| --- | --- |
| 打印指令 | 外部系统提交的业务数据和模板参数，表示希望打印什么内容。 |
| 打印任务（PrintJob） | 服务端持久化的一次打印请求，具有唯一 ID、幂等键和完整状态历史。 |
| 打印模板 | 把业务数据转换为打印内容的版本化规则。 |
| 渲染产物（Artifact） | 根据模板生成的设备文件或预览文件。设备产物优先使用 ESC/POS 字节流。 |
| 设备（Device） | 运行通用网关固件，主动建立 TLS 到 VPS，按目标 IP/端口转发 TCP；不理解打印任务。固件和隧道尚未实现，现有 HTTPS 轮询属于旧设备路径。 |
| 打印机（Printer） | 内网 TCP 目标之一；打印机绑定、协议和能力由 VPS 管理。 |
| 投递尝试（DeliveryAttempt） | 服务端把某个任务租给设备，并等待设备执行结果的一次完整尝试。 |
| 租约（Lease） | 服务端暂时授予某设备处理某任务的时间窗口，过期后任务可重新排队。 |
| 反向 TCP 隧道 | ESP8266 主动建立到 VPS 的 TLS TCP 长连接，承载目标连接、原始数据、信用流控及心跳；无打印业务帧；首版每台设备只允许一个活动代理流。 |
| 打印机发现 | VPS/Web 枚举已配置内网 CIDR 和预设端口，复用 OPEN/DATA 连接目标，VPS 构造并解析探测协议；8266 只转发。 |
| 轮询 | 已实现的旧设备领取任务接口；新通用网关不实现，不自动回退使用。 |
| 打印完成 | 由 VPS 根据目标协议确认；字节已转发不等于出纸，无反馈时记录已发送或结果未知。 |

## 状态语言

- `accepted`：指令已经持久化。
- `rendering`：渲染 Worker 正在生成产物。
- `queued`：设备产物已准备好，等待设备领取。
- `leased`：设备已领取任务，尚未确认开始或完成。
- `printing`：设备正在向打印机发送数据。
- `succeeded`：设备确认本次打印成功。
- `render_failed`：服务端渲染失败。
- `failed`：设备或打印机执行失败。
- `expired`：设备租约超时。
- `cancelled`：尚未执行的任务被取消。
